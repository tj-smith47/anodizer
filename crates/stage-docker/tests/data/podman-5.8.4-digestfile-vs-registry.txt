Recorded run of `podman push --digestfile` and `podman manifest push
--digestfile` against a local `registry:2`, to check the value podman writes
against the digest the registry then serves for the same tag.

podman version 5.8.4 (quay.io/podman/stable:latest)
registry            registry:2, http://localhost:5000
image               FROM scratch + COPY hello /hello

  $ podman push --tls-verify=false --digestfile=/out/push.digest localhost:5000/probe:t
  $ cat /out/push.digest
  sha256:175760276794f3dcc233eda09300ed71cf1bca74add010530480869e7b370b8e
  $ curl -sI -H 'Accept: application/vnd.oci.image.manifest.v1+json, application/vnd.docker.distribution.manifest.v2+json' \
      http://localhost:5000/v2/probe/manifests/t
  Docker-Content-Digest: sha256:175760276794f3dcc233eda09300ed71cf1bca74add010530480869e7b370b8e

  $ podman manifest create probelist
  $ podman manifest add probelist localhost:5000/probe:t
  $ podman manifest push --tls-verify=false --digestfile=/out/manifest.digest probelist docker://localhost:5000/probelist:t
  $ cat /out/manifest.digest
  sha256:d45fc543f733090503ea990e92e6a313195925fd96ed63947f9501549e7d8bd3
  $ curl -sI -H 'Accept: application/vnd.oci.image.index.v1+json, application/vnd.docker.distribution.manifest.list.v2+json' \
      http://localhost:5000/v2/probelist/manifests/t
  Docker-Content-Digest: sha256:d45fc543f733090503ea990e92e6a313195925fd96ed63947f9501549e7d8bd3

Both verbs wrote exactly the digest the registry serves, so the value recorded
as `{{ Digest }}` and compared by the release's docker landing check is the
same kind of value buildx reports under `containerimage.digest`.
